## Scatter и Curve после исправлений

`Scatter` — независимые наблюдения. `Free` сохраняет центр крестика; Lock X/Y
работает только с калибровочными опорами и имеет порог расстояния. Для активной
точки есть два явно разделённых инструмента: привязка к центру растрового
пикселя и подтверждаемый локальный поиск геометрического центра маркера.

`Curve` — однозначная функция `y(x)`. Точки сортируются по X; повторный X,
нечисловые значения и неположительные значения log-оси отклоняются. PCHIP
работает в linear/log10 axis-space, не экстраполирует и обычно надёжнее обычного
кубического сплайна из-за отсутствия ложных осцилляций на монотонных отрезках.

## Что ещё требуется

Приоритет 1:

1. **Affine/projective calibration.** Текущая модель `X=f(px), Y=g(py)` не
   компенсирует поворот, скос и перспективу. Нужны отдельные режимы: affine по
   3+ неколлинеарным 2D-точкам и homography по 4+ углам с residual/reprojection
   error.
2. **Пакетное распознавание повторяющихся маркеров.** Текущий Marker Centre
   намеренно работает только локально с одной активной точкой. Для извлечения
   всей серии нужны настраиваемый ROI, template matching/shape model, просмотр
   всех кандидатов и массовое подтверждение/отклонение.
3. **Автоматическое извлечение Curve.** ROI/mask по цвету, удаление сетки,
   skeleton/median centreline, оценка разброса по толщине и интерактивная
   правка. Имеющиеся старые настройки segmentation/markers отключены, потому
   что соответствующего рабочего pipeline в исходниках нет.

Приоритет 2:

4. Параметрический Curve `x(t), y(t)` для вертикальных участков и петель.
5. Распространение неопределённости клика (например, ±0,5 px) в X/Y и отдельный
   лист Quality в Excel с calibration residuals.
6. Undo/Redo и подтверждение при уменьшении числа серий.
7. Confidence для каждой автоматически найденной стороны рамки; open-axis
   графики сейчас требуют ручной проверки всех четырёх candidate bounds.
8. Полноценная генерируемая major/minor grid snap. Текущий Lock привязывается
   только к введённым опорам, что теперь явно отражено в UI.

## Проверки

- core calibration: linear/log round-trip, residuals, degenerate/NaN/Inf;
- frame centreline: 1/4/7 px, шум, внутренние линии;
- local stroke snap: even-width centre и пересечение линий;
- Curve: endpoints, duplicate X, log axes, no overshoot, sample limit;
- GUI headless: series state, invalidation, crop confirm, clamp sync,
  Save/Load готовой и незавершённой сессии, постоянная рамка, active-point
  лупа, изолированный pixel magnet, стили точек и линии Curve;
- Marker Centre: заполненный/полый круг, квадрат чётной ширины, цвет/шум,
  пересекающая линия, отбраковка одиночного шума и обычного участка кривой;
- Excel: Scatter semantics и фактическая metadata scale;
- compileall и dry-run сборки пакета.

Финальный автоматический прогон: **101 тест успешно**; дополнительно выполнен
offscreen smoke-test главного окна на реальном изображении `DSMC/fig_1.png`.
